# 🏡 Airbnb Analytics Dashboard – Power BI

A multi-page Power BI analytics dashboard developed to analyze Airbnb activity in the Vienna region.  
This project transforms raw Airbnb listing and review data into meaningful, interactive insights using DAX, Power Query, and strong UI/UX dashboard design.

Due to GitHub’s 100MB file size limit, the PBIX file is not included, but all pages of the dashboard have been shared as high-quality screenshots.

---

## 📌 Description

This project presents a complete Airbnb analytics solution built using **Power BI**.  
It provides insights into listings, host behavior, pricing patterns, seasonal trends, customer reviews, and geographical demand patterns.

The dashboard is divided into **six analytical pages**, each designed to answer specific business questions and support decision-making.  
It uses DAX for measures, Power Query for data preparation, map visuals for geographic insights, and sentiment analysis for review understanding.

---

## 🎯 Purpose

The purpose of this dashboard is to help stakeholders understand the Vienna Airbnb market by:

- Identifying high-performing neighborhoods  
- Understanding host behavior, verification trends, and response performance  
- Measuring demand based on customer sentiment and review classification  
- Analyzing occupancy and availability patterns  
- Evaluating price impact on bookings and revenue  
- Visualizing demand clusters using interactive maps  
- Understanding seasonal and time-based revenue fluctuations  

This project is built for **hosts, investors, analysts, and decision-makers** who want to make data-driven improvements in pricing, host performance, and listing strategies.

## 📌 Key Insights (Highlights)

- Entire homes/apartments dominate Airbnb demand.  
- Verified hosts show higher response and acceptance rates.  
- Positive sentiment makes up nearly **90%** of reviews.  
- Winter and spring bring the highest revenue and occupancy.  
- Neighborhoods like **Leopoldstadt, Favoriten, and Landstraße** lead in performance.  
- Price has a moderate impact on occupancy depending on the location.
